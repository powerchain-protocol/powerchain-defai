# @powerchain/clusters

Canonical Solana/Sui cluster registry for PowerChain DeFAI.

Supported environments include mainnet, testnet, devnet, and localnet variants for both chains. Consumers should use this package instead of hard-coding network names or production flags in feature code.

The registry describes chain/environment context only. RPC URLs and credentials remain server-side configuration.

See [`../docs/CROSS_CHAIN_CLUSTERS.md`](../docs/CROSS_CHAIN_CLUSTERS.md).
