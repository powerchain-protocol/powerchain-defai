# @powerchain/staking

Deployment-gated staking feature package for PWRC/wPWRC.

Staking remains fail-closed until verified Solana/Sui staking deployment identifiers and reward sources are configured. The package must not fabricate APR, reward rates, pool state, or deployment availability.

The connected wallet remains the signing authority for staking actions.

See [`../../docs/DEFAI_ARCHITECTURE.md`](../../docs/DEFAI_ARCHITECTURE.md).
