# @powerchain/chat

Feature package for the PowerChain DeFAI assistant.

It owns chat/message/prompt types, curated DeFi prompts, suggestions, saved-prompt state, and chart models consumed by the web shell.

The assistant is advisory only. It must not sign, submit, finalize, settle, or imply authorization for a transaction. Any executable suggestion must re-enter the normal application flow for fresh validation, review, and connected-wallet signature.

See [`../../docs/DEFAI_ARCHITECTURE.md`](../../docs/DEFAI_ARCHITECTURE.md).
