# PowerChain | DeFAI Postman Mocks

Import `PowerChain-DeFAI.mocks.postman_collection.json` and create a Postman mock server from the collection. Postman mock servers use saved response examples from a collection.

Set the collection variable `mockUrl` to the URL Postman assigns to the mock server.

All examples contain `mock: true` and `authoritativeForBridgeAccounting: false`. They are interface fixtures only and never represent real balances, quotes, signatures, execution, finality, market prices, or Wormhole NTT reconciliation.
